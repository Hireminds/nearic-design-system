# Storybook для BOX

Каждый компонент из `@nearic/ui-box` имеет страницу Docs со свойствами, значениями по умолчанию и самостоятельным примером TSX. В Controls можно изменять свойства живого образца. Вкладка Actions показывает вызовы обработчиков. Каноническая тема примеров подключается через `@nearic/ui-box/styles.css` и область `data-family="box"`.

Истории находятся в `stories/*.stories.tsx`. Страницы Docs показывают содержимое файлов из `stories/examples/` — этих же файлов касается строгая проверка TypeScript. При добавлении публичного компонента внесите его доступные варианты, свойства, обработчики и пример импорта.

Из корня репозитория после установки зависимостей и сборки пакетов:

```sh
npm run build --workspace @nearic/box-storybook
npx --no-install playwright install chromium
npm run test:browser --workspace @nearic/box-storybook
```

Проверка запускает временный HTTP-сервер для статической сборки. В Chromium она открывает страницы Docs и истории, меняет значения в Controls и проверяет фокус, блокировку и геометрию переключателя. Для сравнения со старым оформлением можно передать тесту CSS-файл после `--`: его правила применяются к истории Switch до измерения. Овальная дорожка приводит к ошибке проверки формы.
