# Атом Nearic

Открой [контракт библиотеки](../../../specs/001-pulse-library/spec.md), [правила компонентов](../../../docs/components.md) и [конституцию](../../../.specify/memory/constitution.md).

1. Найди ближайший существующий атом и его потребителей. Зафиксируй одну роль элемента и платформы, где она нужна. Проверь, решает ли задачу уже существующий вариант, комбинация атомов или платформенное переопределение. Свяжи изменение с задачей на ревью.
2. Для нового атома или изменения поведения выбери workflow `speckit`. Передай согласованный скоуп и `SPECIFY_FEATURE_DIRECTORY=specs/001-pulse-library`, чтобы дополнить действующий контракт. Для регрессии выбери `bugfix`. Выполни соответствующие шаги в текущем чате по [правилам исполнения](../../../docs/process/chat-workflows.md). Для запроса только на ревью сравни контракт, исходники, публичные экспорты и работающие примеры.
3. В спеке назови пропсы, обязательность, значения по умолчанию и результат каждого применимого состояния. Для `Switch` обычно нужны включён, выключен, фокус и недоступен. Для визуальных отличий укажи типографику, токены и сенсорную область. Перед реализацией значимого изменения покажи спецификацию отдельно от плана.
4. После согласования реализуй атом в `packages/ui-core`. Добавь экспорт BOX в `packages/ui-box`, когда он входит в профиль устройства. Точное отличие темы добавляй в переопределения `ui-box`. Храни реализацию, индекс, CSS-модуль, тест, component.json, историю и пример TSX вместе в папке компонента согласно правилам компонентов. Витрина берёт живые варианты из собранного индекса Storybook. Задай свойствам общие подписи или @labelKey с переводами в обоих словарях. В примерах импортируй компонент по имени из пакета. Новое визуальное решение показывай как «Предложение» до приёмки.
5. Запусти `npm run verify`, `npm run build --workspace @nearic/box-storybook` и `npm run test:browser --workspace @nearic/box-storybook`. Для нового интерактивного поведения или исправленной регрессии добавь проверку наблюдаемого результата. Покажи прямые ссылки на спеку, историю Storybook, PR и фактические результаты CI.
