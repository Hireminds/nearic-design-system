# Nearic Design System

Перед изменением прочитайте [контракт библиотеки](specs/001-pulse-library/spec.md), [правила компонентов](docs/components.md) и [правила токенов](docs/tokens.md). Работайте в согласованном с владельцем скоупе.

Публичный React API принадлежит пакету `@nearic/ui` в `library/`. Каталог и отдельное приложение макетов потребляют этот API. Для полноэкранного прототипа используйте TSX и прямой импорт по имени пакета. Цвета и размеры берите из токенов активного профиля. Обоснуйте добавление отсутствующей примитивной роли или варианта в спеке и покажите его как «Предложение» в каталоге. Экран и образец компонента идут на отдельное ревью владельца.

Перед PR выполните `npm ci` и `npm run verify`. Ветка main публикует каталог и демонстрации через GitHub Actions. Аппаратную проверку BOX и визуальную приёмку указывайте отдельно от результата браузерной сборки.
