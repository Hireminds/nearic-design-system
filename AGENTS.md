# Nearic BOX UI

Перед изменениями прочитайте [контракт библиотеки](specs/001-pulse-library/spec.md), [правила компонентов](docs/components.md) и [правила токенов](docs/tokens.md).

Область репозитория — публичные примитивы дисплея BOX, составные блоки устройства, их токены и каталог. Полноэкранные приложения, их изображения и конфигурации остаются у потребителей библиотеки.

Публичный React API находится в `library/`. Каталог и конструктор импортируют собранные компоненты из `@nearic/ui-box`. Для новой роли опишите состояния, доступность и критерии приёмки в доменной спеке. Покажите образец как «Предложение» до явного решения владельца.

Перед PR выполните `npm ci` и `npm run verify`. При изменении публичной поставки сверьте выходные файлы, список экспортов и потребителя npm-архива. Проверьте затронутые элементы в каталоге, включая размеры касания при ширине 320 px. Аппаратная проверка и визуальная приёмка указываются отдельно.
