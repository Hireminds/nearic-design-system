# Nearic BOX UI

Перед изменениями прочитайте [контракт библиотеки](specs/001-pulse-library/spec.md), [правила компонентов](docs/components.md) и [правила токенов](docs/tokens.md).

Область репозитория — общие токены, независимые примитивы, оформление BOX и составные блоки устройства. Полноэкранные приложения, их изображения и конфигурации остаются у потребителей библиотеки.

Общие значения находятся в `packages/tokens`, общие атомы — в `packages/ui-core`, тематические значения и составные блоки устройства — в `packages/ui-box`. Повторять значения базы в теме запрещено. Каталог и Storybook импортируют собранные пакеты по имени. Для новой роли опишите состояния, доступность и критерии приёмки в доменной спеке. Покажите образец как «Предложение» до явного решения владельца.

Перед PR выполните `npm ci` и `npm run verify`. При изменении публичной поставки сверьте выходные файлы, список экспортов и потребителя npm-архива. Проверьте затронутые элементы в каталоге, включая размеры касания при ширине 320 px. Аппаратная проверка и визуальная приёмка указываются отдельно.

Для добавления, изменения или ревью атома используй [скилл nearic-ui-atom](.agents/skills/nearic-ui-atom/SKILL.md) и [конституцию](.specify/memory/constitution.md).

Для каждого компонента ведите одну папку со стилями, тестом, примером, описанием и историями согласно [правилам компонентов](docs/components.md). Проверьте на витрине ту же историю, которая открывается в Storybook. Проверяйте оба словаря при изменении подписи свойства.
