# Токены «Пульса»

В [источнике токенов](../tokens/tokens.json) каждому значению сопоставлены имя, единица измерения и назначение. Семейство `web` объединяет кабинет и мобильную PWA. Если у записи есть `platforms.mobile`, каталог и компоненты используют это значение на телефоне. Семейство `box` предназначено для интерфейса дисплея 320 × 240. Сборка отдаёт значения в CSS как `--<группа>-<ключ>`, например `--colors-network` и `--size-touch`.

## Что восстановлено из макета

В поле `source` указано происхождение значения и его назначения. `pulse-box` ссылается на прототип «Пульс», `pulse-web` — на выбранный эскиз «Карточки», `proposal` означает дополнение для ревью. Значение может совпадать у двух ролей. Разные имена позволяют впоследствии менять эти роли независимо. [Прототип BOX](https://nearic-box-astryx-studio.sab94a.chatgpt.site/#pulse) · [Эскиз кабинета](https://nearic-box-review-2411.sab94a.chatgpt.site/pulse.html#cards)

## Роли цвета

Служебные цвета `network` и `sound` обозначают конкретную функцию экрана. Цветные состояния `info`, `success`, `warning` и `error` выражают результат или состояние. Ошибка должна иметь пояснение, а действие удаления дополнительно обозначается глаголом на кнопке. Для опасного действия используются заливка `destructive` и подпись `on-destructive`. В источнике токенов поле `role` разделяет нейтральные поверхности, действия, функции системы и обратную связь.

Из watchOS берём принцип постоянного назначения цвета и короткого сценария на небольшом экране. Мятное подтверждение, голубой Wi-Fi и оранжевый звук принадлежат палитре «Пульса». Семантические роли ошибок и предупреждений предложены для её расширения. Цвет сопровождается значком, подписью или числом. [Apple HIG о цвете](https://developer.apple.com/design/human-interface-guidelines/color) · [Проектирование для watchOS](https://developer.apple.com/design/human-interface-guidelines/designing-for-watchos)

## Размеры и доступность

- Размер пиктограммы задаётся отдельно от области касания. Например, плюс 20 px расположен внутри доступной для нажатия кнопки 44 × 44 px. Видимое тело кнопки может быть компактнее.
- На тёмном фоне `focus` задаёт внешний контур фокуса. У интерактивного регулятора используйте `outline` для границы. `track` обозначает пустой участок шкалы; акцентное заполнение и числовая подпись показывают текущее значение.
- При `prefers-reduced-motion: reduce` переход использует `motion.reduced` со значением 0 ms. Состояние, подпись и доступность управления должны обновляться сразу.
- Состояние недоступности сочетается с нативным `disabled` либо с корректной семантикой соответствующего контрола. Параметр `opacity.disabled` меняет только внешний вид.

Команда `python3 tokens/check.py` вычисляет по исходным значениям контраст пар для веба и BOX. Для перечисленных текстовых пар используется порог 4,5:1, для значимой графики и внешнего фокуса — 3:1. На BOX у пары подписи и акцента результат 9,25:1, у голубой иконки и поверхности 8,59:1, у оранжевой иконки и поверхности 8,72:1. Эти числа относятся к значениям цветов. Читаемость и касания на физическом устройстве проверяются при интеграции. [Контраст текста](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) · [Контраст графики и контролов](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)
