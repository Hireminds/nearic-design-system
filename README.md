# Nearic Design System

Дизайн-система Nearic описывает визуальный язык «Пульс» для двух семейств интерфейсов. Веб-компоненты используются в личном кабинете на компьютере и в мобильной PWA. Экран BOX имеет свой профиль 320 × 240 с сенсорным управлением.

## Витрина

В каталоге `preview/` находятся браузерные образцы для ревью. Страница показывает токены рядом с компонентами, которые их используют. Настройки и ответы агенту можно пробовать на демонстрационных данных.

Запустите локальный сервер из корня репозитория.

```sh
python3 -m http.server 8080 --bind 127.0.0.1 --directory preview
```

Откройте [витрину](http://127.0.0.1:8080/pulse-foundations.html). Профили доступны по фрагментам `#desktop`, `#mobile` и `#device`. Образец BOX исполняется в отдельном окне 320 × 240.
