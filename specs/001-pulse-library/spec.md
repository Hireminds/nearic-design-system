# Библиотека и каталог «Пульса»

Статус: предложение на визуальном ревью.

Разработчик берёт независимую деталь или составной блок из типизированного пакета `@nearic/ui`. Автор макета компонует полный интерфейс из тех же экспортов. Владелец сравнивает компоненты и экраны по отдельным ссылкам.

- В каталоге представлены атомы, составные блоки и семантические токены. Типографика и цвета учитывают компьютер, мобильную PWA и экран BOX 320 × 240.
- В образце атома доступны его варианты, применимые состояния и реальный TSX-пример. У составного блока перечислены использованные атомы. Конструктор меняет настройки живого примера и выдаёт TSX для его воспроизведения.
- Полные экраны «Пульса» являются отдельным приложением с зависимостью от пакета. Импорт идёт через публичный API. После изменения библиотечного компонента каталог и экраны получают его при следующей сборке.
- Каталог, собранные экраны и архив пакета получаются из одной Git-ревизии. CI проверяет сборку и публикует статические приложения на GitHub Pages.
- Браузерная демонстрация BOX позволяет открыть запрос с главного экрана, выбрать ответ и поменять громкость. Показанные данные и действия демонстрационные. Реальная прошивка и продуктовый обмен настраиваются в соответствующих репозиториях.
