# Библиотека «Пульс» для BOX

Разработчик интерфейса BOX подключает `@nearic/ui-box` в React и компонует свой экран из базовых элементов. Общий релиз содержит независимо устанавливаемые `@nearic/tokens`, `@nearic/ui-core` и `@nearic/ui-box`. База хранит общие роли, тема BOX переопределяет отличия. UI-пакеты включают точные версии зависимых пакетов Nearic. React предоставляется приложением.

- Атомы покрывают графику, типографику, управление, состояние, навигацию и компоновку. Для интерактивных элементов доступны понятное имя, клавиатура и различимый фокус.
- `NetworkRow` получает обязательные `value` (имя сети) и `online` (наличие соединения). Имя остаётся в одной строке даже при 32 широких символах. Многоточие скрывает только видимое окончание, полное имя остаётся в тексте и подсказке браузера. При потере связи строка показывает «Вне сети» без подсказки с именем. `VolumeControl` отражает текущее значение, сообщает об изменении потребителю и ограничивает нажатия на границах. `DecisionActions` позволяет передать обработчик ответа и текст обоих действий.
- Каталог показывает значения токенов для BOX 320 × 240, интерактивные образцы и состав блоков. На карточке каждое заявленное состояние имеет подпись и отдельный живой образец. С каждой карточки доступна страница Storybook со свойствами и примером TSX. Конструктор обновляет образец и TSX для заданных параметров.
- Архив React-компонентов включает ES-модуль, декларации TypeScript, CSS с токенами и исходные значения в JSON. Потребитель подключает пакет по имени и задаёт область темы `data-family="box"`.
- Сборка создаёт каталог, архив и манифест с контрольной суммой. Проверка поставки сравнивает список файлов и публичных экспортов, проверяет профиль токенов и использование архива в отдельном TypeScript-проекте. Pages публикует эти артефакты из одной ревизии.

Состояния в каталоге демонстрационные. Подключение к устройству и тестирование физического дисплея проходят в работе над прошивкой.

Для переключателя общий атом сохраняет капсулу с прямым центральным участком и круглый бегунок. Область касания от 44 × 44 px, размер бегунка 19 px в базе и 20 px у BOX. Клавиша пробела меняет доступный переключатель. Отключённый сохраняет значение.

`Switch` и `Slider` требуют `label` и поддерживают `onChange` и `disabled`. По умолчанию контролы доступны.

- `Switch` принимает либо `checked`, либо `defaultChecked`. Без обоих параметров он выключен. `name` и `value` сохраняют стандартное поведение при отправке формы, а `min`, `max` и `step` исключены.
- `Slider` принимает либо `value`, либо `defaultValue` как число или числовую строку. По умолчанию браузер выбирает середину диапазона 0–100 при шаге 1. `min`, `max` и `step` сохраняют нативное поведение, а `checked` и `defaultChecked` исключены.

## Публичная витрина и технический Storybook

У каждого компонента есть собственная папка. Автор хранит вместе реализацию, входной файл, стили компонента, тесты, описание и истории. Витрина и Storybook показывают одни и те же истории и состояния. У страницы витрины остаются собственное оформление, рекомендации по применению и прямая ссылка на техническую документацию.

В живом примере посетитель меняет значения через контролы, построенные из описания свойств компонента. Логическому свойству соответствует переключатель, строке — текстовое поле, перечислению — список разрешённых значений, числу — числовой ввод. При заданных границах значение можно менять по шкале и видеть его точное значение. Переключатель «Блокировка» управляет свойством `disabled` и сохраняет подпись в обоих состояниях. Все контролы доступны с клавиатуры и помещаются на экране телефона шириной 320 px. При изменении значения внутри компонента состояние его контрола тоже обновляется. Обработчики событий остаются в технической документации.

Подписи свойств и действий выбираются по ключам из словарей русского и английского языков. Одинаковое по смыслу свойство получает общий ключ. Компонент может назначить свой ключ для более точного названия. В технической документации видно исходное имя пропса. Сборка выявляет неизвестные ключи и пропущенные переводы.

Поверхность Card объединяет произвольное дочернее содержимое на фоне с радиусом и полями из токенов. Поддерживает children и стандартные атрибуты контейнера. В блоке громкости поверхность отвечает за оформление, а сам VolumeControl управляет значением, шагом и доступностью кнопок. На ширине 320 px обе кнопки сохраняют область касания от 44 × 44 px.
