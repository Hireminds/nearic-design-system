# Сборка витрины и Storybook

Каждый компонент хранит реализацию и связанные материалы в собственной папке пакета. Индекс пакета сохраняет импорт по его публичному имени. Реальные CSS-модули собираются вместе с прежними стилями для потребителей. Card предоставляет поверхность блокам настройки.

Storybook обнаруживает истории в папках компонентов. Витрина читает индекс опубликованного Storybook. Для Button сборка дополнительно рендерит HTML из тех же историй с реальным компонентом и стилями пакета. Браузер получает готовые варианты и подключает редактирование основного примера отдельным модулем. Для остальных компонентов каталог встраивает истории Storybook. Главное превью может показывать панель управления. Внутри этого превью Storybook поддерживает одно состояние аргументов для компонента и панели. Навигация по витрине, конструктор и технические страницы доступны по прежним адресам.

Генератор читает типы TypeScript, находит свойства и ключи переводов. Настройки истории уточняют тип контрола и доступные варианты конкретного примера. Словари проходят проверку на совпадение ключей. Приватный Web потребляет инструменты документации как зависимость разработки.

Проверка охватывает типы, сборку и установку архивов в отдельный проект, целостность словарей и источников историй, ссылки между витриной и Storybook, управление в обе стороны и доступность на узком экране.

Для Button отдельно проверяются HTML с отключённым JavaScript, соответствие вариантов историям и редактирование после загрузки клиентского модуля. Холодную загрузку до и после изменения сравнивают при одинаковых настройках сети и окна браузера. Фиксируют время до появления оформленной кнопки и до первого изменения её свойства.
