# Сборка витрины и Storybook

Каждый компонент хранит реализацию и связанные материалы в собственной папке пакета. Индекс пакета сохраняет импорт по его публичному имени. Реальные CSS-модули собираются вместе с прежними стилями для потребителей. Card предоставляет поверхность блокам настройки.

Storybook обнаруживает истории в папках компонентов. Витрина читает индекс опубликованного Storybook и встраивает те же истории. Главное превью может показывать панель управления. Внутри этого превью Storybook поддерживает одно состояние аргументов для компонента и панели. Навигация по витрине, конструктор и технические страницы доступны по прежним адресам.

Генератор читает типы TypeScript, находит свойства и ключи переводов. Настройки истории уточняют тип контрола и доступные варианты конкретного примера. Словари проходят проверку на совпадение ключей. Приватный Web потребляет инструменты документации как зависимость разработки.

Проверка охватывает типы, сборку и установку архивов в отдельный проект, целостность словарей и источников историй, ссылки между витриной и Storybook, управление в обе стороны и доступность на узком экране.
